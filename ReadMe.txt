Holiday Calendar Application

Documentation of Holiday Calendar Application

1. How to navigate through Application

-> Open the page 
-> Selct the country and year from the drop down for which want to see holidays
-> Click on the search button
-> wait till loading indictor is spinning(in case of invalid search it will show "No holidays found")
-> After valid search a table with holidays come up(Holiday Name, Date ,Local Name ,Country Code ,Holiday Type ,Day of the Week) 
-> And a pill with country name and year will show up which is recent search 
-> Recent search data can be fetched from clicking on pill
-> Clear button is also present to clear recent searches

2.Source of Data in website

->Find Holidays over 200+ countries based on country and year selected and
  the Data is coming from "nagerholidays" API endpoint

--->The APIs used in the project
->https://date.nager.at/api/v3/AvailableCountries
